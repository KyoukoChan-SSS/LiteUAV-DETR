# LiteUAV-DETR for Ultralytics

This directory is the Ultralytics interface of LiteUAV-DETR: a modified fork of
[Ultralytics](https://github.com/ultralytics/ultralytics) v8.4.117 that adds
`from ultralytics import LiteUAVDETR`.

Installation, data preparation, training, validation, export, and benchmarking
are documented in the
[Ultralytics section of the main README](../README.md#ultralytics).
